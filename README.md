# Commerce Classes by KV Sir

Professional GitHub Pages website for Commerce Classes by KV Sir.

## Features
- Responsive modern design
- Separate Home, About, Courses, Course Detail, Subscription, Gallery and Contact views
- Class 11, Class 12, B.Com, BBA and MBA course pages
- Student sign-in and account creation demo
- Student dashboard, profile and My Courses
- Browser-based course enrollment
- WhatsApp enquiry
- GitHub Pages ready

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

## Important
The student account in this static version uses browser `localStorage` and is a demo only. It is not a secure production authentication/database system. For real student accounts across devices, connect a backend/database such as Firebase, Supabase or another server.
